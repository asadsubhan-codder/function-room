# Function Room

An Ontario Grade 11 MCR3U mastery room, aligned to the supplied teacher calendar and lessons 1.1–1.7.

This GitHub Pages edition is independent of ChatGPT. Unit 1 uses sequential lesson gates, Ontario/Nelson video instruction led by Ms Havrot, authentic Ontario teacher quizzes and tests, generated six-part practice checks, fresh delayed retrieval, typed explanations, an error log, and 40-minute unseen cumulative mocks. Units 2–7 remain available as a video-first course library.

The readiness standard is intentionally strict: correct every lesson check, prove it again after a delay, clear the repair queue, and earn 100% on two different generated mocks. It is a study criterion, not a guarantee of a school mark.

## Deployment

Push the repository's `main` branch to GitHub. The included workflow builds the Vite app and publishes the `dist` folder with GitHub Pages.

The deployment workflow is stored in `.github/workflows/deploy.yml`.
