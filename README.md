# Function Room

An Ontario Grade 11 MCR3U mastery room, aligned to the supplied teacher calendar and lessons 1.1–1.7.

This GitHub Pages edition is independent of ChatGPT. Unit 1 uses sequential lesson gates, multiple video explanations, Ontario worksheets, shuffled mastery checks, delayed retrieval, an error log, and a mixed mock. Units 2–7 remain available as a video-first course library.

## Live site

https://asadsubhan-codder.github.io/function-room/

Progress is stored in the browser. Export a progress file to move it between an iPad and laptop.

## Local preview

    npm install
    npm run dev

## Deployment

Push the repository's `main` branch to GitHub. The included workflow builds the Vite app and publishes the `dist` folder with GitHub Pages.

The deployment workflow is stored in `.github/workflows/deploy.yml`.
